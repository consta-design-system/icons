import { MdxTabs } from '@consta/stand';

Эта библиотека содержит все иконки для дизайн-системы Consta. [Посмотреть на GitHub](https://github.com/consta-design-system/icons)

## Быстрый старт

#### Установите пакет и зависимости

<MdxTabs labels={['npm', 'yarn']} view="clear">
<>

```cli
npm install @consta/uikit @consta/icons
```

</>

<>

```cli
yarn add @consta/uikit @consta/icons
```

</>
</MdxTabs>

#### Подключите тему

Тему обязательно нужно подключать в корне приложения, так, чтобы все компоненты `@consta/icons` были вложены в компонент `Theme`.

#### Всё!
